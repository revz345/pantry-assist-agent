```
│   │   ├── db/        # SQLModel engine/session
│   │   ├── models/    # Pydantic/SQLModel schemas

│   │   └── templates/ # Server-rendered HTML UI
│   ├── tests/         # pytest + TestClient
│   ├── scripts/seed.py  # Indian/Idli-Dosa demo data
│   └── pyproject.toml # ruff, pytest, uvicorn config
├── imessage-bridge/   # macOS-only: polls iMessage → OpenClaw + Pantry API
│   ├── pantry_bridge/  # bridge package (config, parser, imessage, clients, handler, main)
│   ├── pantry_mcp.py   # MCP stdio server exposing the Pantry API to the agent
│   ├── tests/          # pytest (test_bridge.py, test_mcp.py)
│   ├── scripts/        # run_bridge.sh launcher
│   └── legacy/         # superseded AppleScript bridge

```

## In-App Background Agent

- **File:** `backend/app/services/agent.py`
- **Runs:** Periodic async task (APScheduler configured in settings, not yet wired to lifespan)
- **Does:** Generates recipe suggestions via LLM, checks expiry alerts
- **LLM:** OpenAI-compatible (configured for local llama.cpp/Ollama via `OPENAI_BASE_URL`)
- **Trigger manually:** `POST /api/v1/agent/run` (requires `DEBUG=true`)

## Web UI (Server-Rendered)

- Jinja2 templates in `backend/app/templates/`
- Routes mounted at `/` (redirects to `/items`), `/items`, `/locations`, `/reminders`, `/recipes`
- Flash messages via Starlette sessions

## iMessage Bridge (Separate Component)

- **Package:** `imessage-bridge/pantry_bridge/` (entrypoint: `python -m pantry_bridge`)
- **MCP server:** `imessage-bridge/pantry_mcp.py` (registered with OpenClaw)
- **Requires:** macOS, iCloud Messages signed in, Automation permission for Terminal
- **Polls** iMessage every 5s, forwards commands to Pantry API + OpenClaw gateway
- **Run:** `cd imessage-bridge && ./scripts/run_bridge.sh` (installs deps, sets `IMESSAGE_CONTACT`)

## Conventions (Enforced)

- **Python:** `pyproject.toml` + ruff (lint/format), pytest, uvicorn. No `requirements.txt`.
- **SQLModel** for DB models + Pydantic for API schemas (single source in `models/schemas.py`).
- **Settings** via `pydantic-settings` + `.env` (see `backend/.env.example`).
- **Async** throughout (FastAPI, httpx, openai client).
- **Tests:** In-memory SQLite (`sqlite://` + `StaticPool`), override `get_session` dependency.
- **No mobile package yet** — API is the contract.

## Gotchas

- **Agent auto-runs** via APScheduler in the FastAPI lifespan (startup + every `AGENT_INTERVAL_MINUTES`); check `GET /api/v1/agent/status`.
- **Web UI templates** expect `app/static/` directory (missing — 404s on `/static/`).
- **iMessage bridge** `scripts/run_bridge.sh` and the MCP registration reference the absolute repo path (resolved at runtime from `$REPO_ROOT` / the script's own location — no hardcoded machine path).
- **No auth** on API (intended for local/trusted network only).
- **SQLite file** at `backend/pantry.db` (gitignored? check before commit).

### Vision LLM Integration (Receipt Scanning)

**Models to try (Ollama):**
- `minicpm-v:8b` — Best for structured OCR (receipts, tables)
- `llava:7b` — Good general vision, faster
- `bakllava:7b` — Mistral-based, strong text extraction

**Implementation sketch:**
```python
# backend/app/services/vision.py
async def extract_items_from_receipt(image_b64: str) -> list[ItemCreate]:
    client = AsyncOpenAI(base_url="http://localhost:11434/v1", api_key="dummy")
    prompt = """Extract shopping items as JSON:
    [{"name": "string", "quantity": float, "unit": "g|kg|l|ml|pcs", "price": float, "category": "produce|dairy|pantry|frozen"}]
    Return ONLY valid JSON."""
    response = await client.chat.completions.create(
        model="minicpm-v:8b",
        messages=[{"role": "user", "content": [
            {"type": "text", "text": prompt},
            {"type": "image_url", "image_url": {"url": f"data:image/jpeg;base64,{image_b64}"}}
        ]}],
        temperature=0.1
    )
    return parse_and_validate(response.choices[0].message.content)
```

**Endpoint:** `POST /api/v1/items/scan-receipt` (multipart form: image file)

**iMessage bridge command:** `scan receipt <image_url>`
